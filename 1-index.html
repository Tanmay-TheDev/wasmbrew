Self-contained in-browser runtimes
All four languages execute locally inside your browser tab without external server APIs or broken CDN dependencies.

        
      

      

        
PY
Python 3 · In-Browser Engine
Supports Python 3 syntax, f-strings, comprehensions, slicing, unpacking, classes/OOP, recursion, exceptions, and built-in modules (math, random, collections, itertools, functools, heapq, bisect, re, json, statistics).

        
C++
C++20 · In-Browser Compiler + STL
Compiles C++20 source with support for iostream (cin, cout, getline), printf/scanf, iomanip, structs/classes, lambdas, templates, and STL containers (vector, string, map, unordered_map, set, priority_queue, stack, queue, pair, algorithm, cmath).

        
JVM
Java · In-Browser Compiler + JDK
Compiles and executes Java classes, records, enums, lambdas, System.out (println, print, printf), Scanner(System.in), BufferedReader, StringTokenizer, StringBuilder, Arrays, Collections, ArrayList, HashMap, TreeMap, HashSet, TreeSet, PriorityQueue, and BigInteger.

        
JS
JavaScript · Isolated Worker / Sandbox
Executes modern ES2024+ JavaScript with async/await, input()/prompt()/readline() wired to Standard Input, rich console formatting, and loop timeout protection.

      

      
All source code is persisted in browser localStorage and runs locally inside this tab. REA project ↗ · TeaVM javac ↗
