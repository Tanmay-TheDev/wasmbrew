Self-contained in-browser runtimes & GUI
All four languages and live HTML/Canvas previews execute locally inside your browser tab.

        
      

      

        
PY
Python 3 · In-Browser Engine
Supports Python 3 syntax, f-strings, comprehensions, slicing, unpacking, classes/OOP, recursion, exceptions, and built-in modules. (Note: desktop toolkits like tkinter/PyQt cannot render native windows in a browser.)

        
C++
C++20 · In-Browser Compiler + STL
Compiles C++20 source with support for iostream (cin, cout, getline), printf/scanf, iomanip, structs/classes, lambdas, templates, and STL containers (vector, string, map, set, priority_queue, algorithm).

        
JVM
Java · In-Browser Compiler + JDK
Compiles and executes Java classes, records, enums, lambdas, System.out, Scanner(System.in), StringBuilder, Arrays, Collections, ArrayList, HashMap, TreeMap, HashSet, PriorityQueue, and BigInteger.

        
GUI
HTML / CSS / JS · Sandboxed GUI Preview
Renders index.html with linked open CSS/JS files inside a sandboxed iframe, and lets JavaScript files draw directly to <canvas id="canvas"> and DOM elements.

      

      
All project files persist in browser localStorage. AI Help uses free keyless endpoints (LLM7 / Pollinations) only when you send a message.
